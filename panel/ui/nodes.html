Как это работает

Мастер ставит ноду по SSH (domain + login + pass), включает agent token и пушит клиентов/inbounds. Галочка Outbound поднимает на ноде VLESS/WS bridge — мастер получает outbound node_… (клиенты могут уходить через эту ноду). Обновить ставит свежий релиз панели на выбранную ноду (по agent API; для старых агентов — SSH-пароль). Сделать мастером передаёт роль: текущая панель становится агентом, выбранная нода — новым мастером (нужен SSH-пароль).
