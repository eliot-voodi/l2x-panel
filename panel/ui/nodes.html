Как это работает

Мастер ставит ноду по SSH (domain + login + pass, порт любой). Обычная нода: открыт :443, мастер пушит конфиг, Outbound = VLESS/WS bridge на ноде. Нода за NAT: входящих портов нет (SSH достаточно). Нода сама тянет конфиг с мастера и держит зашифрованный VLESS+WS+TLS туннель на домен мастера (выглядит как обычный клиентский WS). На мастере появляется outbound node_… через Xray reverse portal — маршруты, балансеры, подписка. Reverse — тот же туннель «нода → мастер», но для любой обычной ноды (вкл/выкл кнопкой): мастер не подключается к ноде, outbound node_… идёт через reverse portal. Push-конфиг и управление остаются прежними. Зеркало — только для обычных нод (полная копия для → Master). Расписание — авто-sync (для NAT — обновление payload, который нода заберёт сама).
