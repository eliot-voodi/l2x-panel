Как это работает

Мастер ставит ноду по SSH (domain + login + pass, порт любой). Обычная нода: открыт :443, мастер пушит конфиг, Outbound = VLESS/WS bridge на ноде. Нода за NAT: входящих портов нет (SSH достаточно). Нода сама тянет конфиг с мастера; egress — L2X-туннель (профиль: No DPI / DPI lite / UDP). На мастере outbound node_… через l2x-tunneld SOCKS. +Reverse — тот же L2X-туннель «нода → мастер» для обычной ноды; профиль переключается селектором. Зеркало — только для обычных нод (полная копия для → Master). Расписание — авто-sync (для NAT — обновление payload, который нода заберёт сама).
