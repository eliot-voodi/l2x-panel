Как это работает

Мастер ставит ноду по SSH (domain + login + pass), включает agent token и пушит клиентов/inbounds. Галочка Outbound поднимает на ноде VLESS/WS bridge — мастер получает outbound node_…. Зеркало — полная копия мастера на ноде (клиенты, outbounds, маршруты, реестр нод). В обычном режиме нода остаётся outbound/agent; при сбое → → Master без потери данных (для зеркала SSH не обязателен). → Master сначала поднимает новую ноду и проверяет health; старый master сдаёт роль только после подтверждения. На новый master уходят все данные, включая все outbound’ы; outbound на саму эту ноду (node_…) убирается, ссылки клиентов/маршрутов → direct. Обновить ставит свежий релиз на выбранную ноду. Расписание — авто-sync каждой ноды по своему интервалу (5 мин … 24 ч).
