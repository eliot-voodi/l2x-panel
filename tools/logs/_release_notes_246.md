## v2.4.6 — RU через сервер + outbound’ы ядра в маршрутах

- Клиентский JSON больше **не** шлёт `geoip:ru` / `category-ru` в direct — RU остаётся в туннеле, маршрутизацию делает сервер.
- В правилах ядра outbound `direct` / `lb_*` / `node_*` на клиенте = через VPN; обход только у **Client**.
- В дропдауне маршрутов снимка ядра видны outbound’ы мастера (ноды и custom).
